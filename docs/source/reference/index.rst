Quick Description
-----------------

*A short description of each module and its function*

- gregium - Holds version info
- ascii_render - Rendering with colored characters to a standard terminal
- command_tree - A shlex-like system that parses python functions and an input string as though they were commands
- easing - General easing functions
- ghttp - Easy to use but powerful HTTP server
- json_matcher - Verification for JSON files and schemas
- llm - API for large language models
- logger - Styling for loggers
- misc - Miscellaneous function
- server - Socket servers
- stt - Speech-To-Text api
- terminal - Additional inputs for blessed terminals
- tts - Text-To-Speech queues
- vector - Vector type and vector math
- verification - Verification for installed modules
